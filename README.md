# 🖼️ NFTC – NFT Marketplace Landing Page

NFTC is a modern and responsive NFT marketplace landing page designed to showcase digital assets, NFT collections, top creators, and marketplace features. The website focuses on delivering an engaging user experience through a clean UI, responsive design, and interactive elements.

## 🌐 Live Demo

🔗 https://minar-nftc.vercel.app/

## 📂 GitHub Repository

🔗 https://github.com/minar-hossain82/nftc

## ✨ Features

* 🖼️ Modern NFT marketplace landing page
* 📱 Fully responsive design
* 🚀 Attractive hero section
* 🔍 Explore NFT collections
* 💰 NFT prices displayed in ETH
* 🏆 Top sellers showcase
* 🎨 Popular NFT collections
* 👨‍🎨 Artist and creator showcase
* 💳 Wallet connect interface
* 📖 How It Works section
* 🍔 Responsive mobile navigation
* ⬆️ Back-to-top button
* ⚡ Smooth user experience
